# Teams Voice Toolkit

A collection of PowerShell tools, labs, and documentation for
Microsoft Teams Phone, Direct Routing, and Unified Communications operations.

## 🎯 Purpose

This repository is part of my UCInfraSecOps development journey.

The goal is to build practical experience using PowerShell and automation
to improve the operation, visibility, security, and supportability of
enterprise communications environments.

## 📞 Focus Areas

- Microsoft Teams Phone
- Teams Direct Routing
- PowerShell
- Voice Operations
- SBC Health
- Configuration Inventory
- Reporting
- Troubleshooting
- Automation

## 🧭 Engineering Approach

For each tool I build, I try to consider:

1. What operational problem does this solve?
2. What data is required?
3. What permissions are required?
4. How should errors be handled?
5. What should be logged?
6. Could the process be automated safely?
7. How would this operate at enterprise scale?
